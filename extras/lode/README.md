# lode themes

Generated by `scripts/build lode` from the lvim-colorscheme palettes — one file
per style, 48 in all. The generator is
`lua/lvim-colorscheme/extra/misc/lode.lua`, and its header carries the full
reasoning: why the surfaces are derived rather than copied (the palette's own
tiers sit about 1.06:1 apart, which an editor wants and a windowed application
cannot use), which surface each foreground is grounded against, and what is
deliberately left uncorrected.

Install:

```sh
mkdir -p ~/.config/lode/themes
cp extras/lode/*.toml ~/.config/lode/themes/
```

Then pick one in lode's Theme menu, or set `LODE_THEME` to a file's stem
(`LODE_THEME=LvimBase_dark`). `$LODE_THEME_DIR` overrides the search path, and
the first directory wins a name clash — which is what regenerating palettes into
a scratch directory needs.

## Checking them

`check.py` re-measures every file against the floors the generator promises and
prints a line per theme:

```sh
python3 extras/lode/check.py
```

It is a check, not a fixer: it reports, and a failure means the generator needs
looking at, not the file editing by hand.
